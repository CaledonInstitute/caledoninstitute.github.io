# Caledon Institute

Website for an independent community exploring vulnerability research and artificial intelligence, based in Bandar Lampung, Indonesia.

Home, About, and Members pages in English and Indonesian. Built with Next.js, TypeScript, and Tailwind CSS. Exported as a static site for GitHub Pages.

## Development

```sh
npm ci
npm run dev
```

`npm run build` generates the static site in `out/`. `npm run lint` checks the code.
